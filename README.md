# Ghania Sheikh — Player 01 Portfolio

A responsive, black-and-white retro arcade-style portfolio made with plain HTML, CSS and JavaScript. No build tools or paid services are required.

## Files

- `index.html` — all portfolio content and sections
- `styles.css` — responsive styling, monochrome arcade look and animations
- `script.js` — scroll reveals, text-edit mode, mobile navigation and optional sound effects
- `assets/` — supplied certificate images

## Preview locally

1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For the best local preview, use VS Code with the Live Server extension.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new **public** repository, for example `ghania-sheikh-portfolio`.
2. Upload all files and folders from this ZIP. Make sure `index.html`, `styles.css`, `script.js` and the `assets` folder are at the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. Your site URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/ghania-sheikh-portfolio/`

If you instead name the repository `ghania12900-ctrl.github.io`, the site can be published at:
`https://ghania12900-ctrl.github.io/`

## Editing the content

- Open `index.html` in any text editor.
- Search for the text you want to change and edit it.
- The on-page **EDIT TEXT** button lets you temporarily edit text in the browser. Those browser edits do not automatically save back to your website files. To make permanent changes, edit `index.html` and upload the updated file to GitHub.
- Replace certificate images in `assets/` if you have higher-quality copies. Keep the same filenames, or update the image paths in `index.html`.

## Personal details and privacy

The website includes the contact details and social links supplied for this portfolio. Since the site is public, visitors will be able to see the listed phone number and email addresses. Remove or change any detail you do not want publicly displayed before publishing.

## Notes

- The website uses a Google Fonts import for Space Grotesk and Space Mono. If the fonts cannot load, it falls back to system fonts.
- Sound effects are optional and start off. Visitors must turn them on themselves.
- The site respects the device's reduced-motion preference.
- The supplied CV screenshot is not displayed as an image; its details are represented as editable website text.
